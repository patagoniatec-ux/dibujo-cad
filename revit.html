Del papel al modelo digital

Del croquis a Revit e Inventor

Dos rutas de trabajo con IA: metodología BIM para proyectos de arquitectura con Revit y diseño mecánico paramétrico con Inventor. En ambos casos partimos de un croquis, verificamos las medidas y preparamos documentación técnica revisable.

La idea central

Vos hacés el croquis. La IA ayuda a convertirlo en un proyecto documentado.

Partimos de una fotografía o escaneo de una planta dibujada a mano. Primero se leen las cotas y se aclaran las dudas; después se define la geometría y se construye el modelo en Revit mediante herramientas de automatización compatibles.

El objetivo no es “adivinar” el plano: es conservar las medidas, detectar datos faltantes y dejar cada decisión lista para revisión profesional.

El recorrido de trabajo

Recibir el croquis

Foto nítida, cotas generales y parciales, espesores, niveles y referencias.

Interpretar y consultar

Ordenar medidas, detectar contradicciones y preguntarte lo que no se puede deducir.

Modelar en BIM

Crear niveles, muros, aberturas, losas y componentes según las decisiones aprobadas.

Documentar y revisar

Preparar vistas, cortes, fachadas, cotas, planillas y láminas; comprobar coherencia.

¿Qué podría mostrar el proyecto terminado?

01 · Planta

Planta arquitectónica

Distribución, espesores, puertas, ventanas, cotas y niveles. Las cotas deben coincidir con el croquis validado.

02 · Modelo

Modelo BIM 3D

Volumetría y componentes constructivos organizados por niveles y categorías, con parámetros editables.

03 · Documentación

Láminas técnicas

Plantas, cortes, fachadas, detalles y planillas organizadas en hojas para exportar a PDF.

04 · Interfaz

Pantalla de trabajo

Una vista de referencia para reconocer el navegador del proyecto, las propiedades y el área de modelado. La interfaz real depende de la versión de Revit.

Documentación que podemos preparar

Arquitectura

  • Planta general y de cotas
  • Planta de replanteo
  • Cortes longitudinales y transversales
  • Fachadas y detalles
  • Planillas de aberturas y superficies

Construcción y estructura

  • Plantas de fundaciones, cuando exista diseño validado
  • Plantas estructurales y detalles constructivos
  • Cuadros de cantidades y planillas
  • Hojas y láminas de impresión
  • Exportación y revisión de PDF

La documentación estructural y de fundaciones no se obtiene de forma segura solo a partir de una planta arquitectónica: requiere datos de suelo, cargas, criterios de cálculo, normativa y validación profesional.

¿Qué hace falta para empezar?

  1. Un croquis legible con al menos dos cotas generales y las cotas parciales disponibles.
  2. Espesores de muros, alturas, niveles y ubicación de aberturas, si se conocen.
  3. La versión de Revit y las familias o plantillas que se utilizarán.
  4. Una instancia de automatización/MCP compatible, instalada y conectada al programa.
  5. Revisión del modelo y de las láminas antes de considerarlas documentación válida.
Importante sobre MCP: Autodesk publica un servidor MCP oficial para Revit 2027.2 en Technical Preview. La documentación indica conexión local y clientes de IA compatibles con MCP, como Claude Desktop y Cursor. No debemos prometer que ese servidor se conecta directamente a ChatGPT sin comprobar un puente o cliente compatible. Las herramientas de escritura pueden modificar el modelo, por eso conviene trabajar con copias y revisar los cambios.

Segunda ruta · Diseño mecánico y fabricación

Del croquis a Inventor

El mismo enfoque de trabajo, aplicado al diseño de piezas y conjuntos mecánicos: interpretar medidas, construir geometría paramétrica, revisar el modelo y preparar planos para fabricación.

La propuesta

Un croquis acotado puede convertirse en una pieza 3D editable.

Partimos de una fotografía o escaneo. Identificamos cotas, diámetros, espesores, radios, referencias y tolerancias disponibles. Antes de modelar, se aclaran las medidas dudosas y se acuerda el sistema de referencia.

Con Inventor abierto en la PC, un servidor MCP local puede transmitir operaciones al programa mediante su API. La IA propone la secuencia; el usuario revisa y confirma los cambios.

Qué permite automatizar el MCP elegido

Para esta ruta se toma como referencia ipt-mcp de BIMwright, un proyecto de código abierto que conecta un cliente MCP con la API nativa de Autodesk Inventor. El repositorio documenta herramientas para croquis, operaciones de modelado, parámetros, ensamblajes y exportación. El alcance exacto depende de la versión publicada y de los módulos habilitados.

1. Croquis y operaciones

Crear perfiles 2D, restricciones y cotas; extruir, revolucionar, perforar, vaciar, redondear, achaflanar y repetir operaciones.

2. Ensambles

Consultar ocurrencias, organizar componentes, ubicar piezas y revisar relaciones de conjunto según las herramientas habilitadas.

3. Planos y exportación

Crear hojas y vistas, cortes, cotas, anotaciones, tablas y exportaciones. Las herramientas de dibujo documentadas están orientadas a Inventor 2027 y requieren verificar su disponibilidad por versión.

Ejemplo visual publicado por el proyecto

Ficha técnica del puente MCP

Arquitectura de conexión

  • Servidor MCP: proceso local que habla MCP por entrada/salida estándar (stdio).
  • Complemento de Inventor: add-in cargado dentro de Inventor.exe.
  • Comunicación interna: TCP local para Inventor 2022–2024; canal con nombre para 2025–2027.
  • API: Autodesk Inventor API / COM, ejecutada en el hilo principal de Inventor.
  • Unidades: longitudes en milímetros y ángulos en grados en las herramientas.
  • Seguridad: conexión local autenticada; las escrituras requieren identificar y confirmar el documento de destino.

Versiones y compatibilidad

  • Inventor 2022, 2023 y 2024: destino .NET Framework 4.8; transporte TCP local.
  • Inventor 2025 y 2026: destino .NET 8 para Windows; canal con nombre.
  • Inventor 2027: destino .NET 10 para Windows; canal con nombre.
  • El instalador publicado y los complementos incluidos pueden cubrir menos versiones que el código fuente.
  • El repositorio indica que el paquete de instalación de la versión documentada incluye Inventor 2025 y 2027; otras versiones requieren compilar el complemento con las referencias de Inventor correspondientes.
Importante si usamos Inventor 2023: el proyecto declara compatibilidad de código con 2023, pero el instalador publicado no incluye necesariamente ese complemento ya compilado. Para esa versión hay que preparar el add-in con las bibliotecas de interoperabilidad instaladas en la PC y probarlo localmente. No conviene ejecutar un instalador de otra versión ni copiar DLL al azar.

Cómo sería el trabajo desde el croquis

Medir e interpretar

Identificar cotas, diámetros, radios, espesores, unidades, tolerancias y referencias.

Definir la estrategia

Elegir plano de origen, geometría base, restricciones y secuencia de operaciones.

Modelar y ajustar

Crear la pieza paramétrica y cambiar medidas mediante parámetros, con revisión en pantalla.

Documentar y exportar

Preparar vistas y planos; exportar STEP, STL o DXF cuando corresponda y verificar el resultado.

Qué necesitamos en la computadora

  1. Windows y una instalación licenciada de Autodesk Inventor de la versión compatible.
  2. Inventor abierto y el documento correcto seleccionado.
  3. El complemento/add-in de ipt-mcp compilado para esa versión y el servidor MCP local.
  4. Un cliente compatible con MCP (por ejemplo, Codex, Cursor o Cline) configurado para iniciar el servidor local.
  5. Una copia de seguridad del archivo antes de las primeras pruebas y revisión humana de cada operación.
Conexión con ChatGPT: ipt-mcp está diseñado para clientes MCP locales por stdio. Eso no significa que ChatGPT en el celular o en la nube pueda abrir directamente un proceso de Windows. Para usarlo desde ChatGPT directamente haría falta una pasarela remota compatible y segura; como primera prueba, el camino más directo es un cliente local en la misma PC que Inventor. No se debe publicar el puerto local de Inventor en Internet.

Herramienta de inteligencia artificial · Modelado 3D

De una fotografía a un modelo 3D: Tencent HY 3D Global

¿Qué es?

Abrir Tencent HY 3D Global ↗

Es una herramienta de Tencent que permite generar modelos tridimensionales a partir de una imagen (Image-to-3D) o de una descripción escrita (Text-to-3D). También ofrece opciones de generación con varias vistas y herramientas de geometría y texturizado, según el modelo y el servicio disponible.

¿Para qué nos sirve? Para transformar una foto, un objeto de referencia o una idea en un primer modelo 3D que luego podemos revisar y continuar trabajando en un programa de modelado.

1. Image-to-3D

Subir una fotografía o imagen de referencia para obtener una representación tridimensional. Una sola vista puede ocultar partes del objeto; varias vistas ayudan a describirlo mejor cuando la plataforma las admite.

2. Text-to-3D

Describir el objeto, su forma, materiales y estilo para generar una propuesta 3D. Es útil para explorar ideas y crear referencias visuales.

3. Revisar y continuar

Comprobar escala, proporciones, geometría, malla y formato de exportación antes de llevar el resultado a Blender, Inventor u otro programa.

Evaluación para impresión 3D: es una buena herramienta para crear una primera forma o una referencia visual, pero no debemos considerar automáticamente que el modelo tenga medidas exactas, paredes con espesor correcto o una malla lista para imprimir. Antes de usarlo en la Ender 3 V2, hay que comprobar el archivo exportado, repararlo si hace falta y verificarlo en el laminador. La disponibilidad de créditos gratuitos, formatos de descarga y límites puede cambiar según la cuenta y el servicio.
